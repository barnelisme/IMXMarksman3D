# IMX-kam-2026 source snapshot

This branch captures the local Unity 6000.2.12f1 source work in progress.
Included: scripts, prefabs, materials, scenes below 50 MiB, matching Unity metadata, Packages, and ProjectSettings.

Deferred additions: large models and textures, audio/video, baked lighting and terrain data, third-party packages under Assets, machine settings, training results, and these oversized scenes:
- Assets/Basic1Lane3DClayPigeon.unity
- Assets/Basic1LaneBirdHunting.unity
- Assets/DirectCoastForestHunting.unity

Some included scenes and prefabs reference deferred assets. This snapshot is not a complete standalone build.
Existing binary assets in the parent commit remain in history.
No gameplay fixes were applied for this snapshot. Play Mode and build validation have not been performed.
